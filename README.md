📊 Power BI Sales Analysis & Forecast Dashboard

An interactive Power BI dashboard built to analyze sales performance and generate forecast insights using historical retail data.

This project focuses on transforming raw sales data into meaningful business insights through data modeling, visualization, and forecasting.

---

🚀 Project Overview

This dashboard helps answer key business questions such as:
- How are sales and profits performing over time?
- Which categories and regions drive the most revenue?
- What are the future sales trends based on historical data?

The project combines **descriptive analytics** and **predictive forecasting** to support data-driven decision making.

---

🧩 Key Features

- 📈 Sales & profit trend analysis  
- 🌍 Region-wise and category-wise performance  
- 🛒 Product-level insights  
- 🔮 Sales forecasting with confidence interval (95%)  
- 🎛️ Interactive slicers for dynamic filtering  

---

🛠 Tools & Technologies

- **Power BI Desktop**
- **Power Query** for data cleaning & transformation
- **DAX** for calculated measures
- **CSV datasets** as data sources

---

📂 Dataset Information

| File Name | Description |
|----------|------------|
| `SuperStore_Sales_Dataset.csv` | Historical sales data |
| `Forecast-95%.csv` | Forecasted sales output |
| `final_sales_data.pbit` | Power BI template file |
